What this is: XenonSec rewrites your code so it is hard to read. It is not an unbreakable lock: anyone who can run the code can, with effort, recover its behaviour. Use it to raise the cost of reading, not to hide secrets. Never put passwords or API keys in client-side code.

Use it only on code you own or have permission to protect.

Requests are processed on the server in a temporary folder that is deleted after each run. Nothing is logged or stored by the playground.
